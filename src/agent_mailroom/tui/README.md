**Terminal user interface for the agent-mailroom package.**

## Purpose

The TUI provides a terminal-based interface:
- Floor visualization
- Agent status display
- Mail queue monitoring
- Manual intervention

## Usage

```bash
cd packages/agent-mailroom
uv run python -m agent_mailroom.tui
```
